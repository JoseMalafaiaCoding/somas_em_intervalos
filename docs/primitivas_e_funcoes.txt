Na v4, o laço interno executa n/2 vezes porque cada iteração processa 
dois elementos do vetor (v[i] e v[i + 1]), 
enquanto o índice avança duas posições (i += 2). 
Assim, para percorrer os n elementos, são necessárias apenas n/2 iterações

Na v5, o primeiro while processa quatro elementos por iteração, 
executando n/4 vezes por consulta. 
Como temos q = n, o total é n²/4 execuções, quando n é divisível por 4.

O segundo while processa os elementos restantes, 
executando n mod 4 vezes por consulta. 
Quando n é múltiplo de 4, seu corpo não é executado, 
mas a condição ainda é testada.
